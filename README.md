## 三、关键词说明

- **降AIGC**：指降低文本的 AI 生成痕迹，使其更接近人类写作风格，从而通过 AI 内容检测工具。
- **AIGC 检测**：识别文本是否由 AI（如 ChatGPT、GPT-4 等）生成的技术。
- **AI 水印**：在 AI 生成内容中嵌入不可见标记，用于追踪来源。
